# psxneko

A tiny cat for your Playstation 1!

![neko!](neko.gif)

## Requirements

- [PSX.Dev extension](https://marketplace.visualstudio.com/items?itemName=Grumpycoders.psx-dev) for VSCode
- [mkpsxiso](https://github.com/Lameguy64/mkpsxiso) if you want to burn a real CD
- a valid LICENSEx.DAT file (also for burning to a real CD)

## Building

Restore the third-party tools using the PSX.Dev extension menu and run `make`. To generate the CD image, run `mkpsxiso CDLAYOUT.xml`.
